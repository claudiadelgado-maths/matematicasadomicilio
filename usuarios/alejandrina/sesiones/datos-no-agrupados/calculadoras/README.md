# Calculadoras de la sesión

Contiene herramientas exclusivas de Datos no agrupados. `estadistica-descriptiva/` genera una tabla de seis columnas, medidas, procedimientos y dos gráficas a partir de enteros o decimales.

No deben aparecer en el índice público de calculadoras salvo decisión expresa. La lógica estadística común se importa desde `../estadistica.mjs`.
