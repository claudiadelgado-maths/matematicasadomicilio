# Ejercicios de la sesión

Contiene prácticas exclusivas de Datos no agrupados. `organiza-y-analiza/` reúne cinco actividades sobre orden, frecuencias, acumulados, interpretación y medidas de tendencia central.

Cada subcarpeta debe poder modificarse y probarse sin acceder a otro usuario. La lógica estadística común se importa desde `../estadistica.mjs`.
