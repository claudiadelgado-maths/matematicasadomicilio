# Calculadoras de Diagramas de árboles

Contenedor de herramientas exclusivas de esta sesión.

## Herramientas actuales

- `constructor-de-diagramas/`: calculadora publicada para crear una colección, definir etapas, elegir si hay repetición y estudiar el árbol resultante.

La herramienta reutiliza `../arboles.mjs`, no calcula probabilidades y limita únicamente la visualización de árboles excesivamente grandes para mantenerlos comprensibles.
