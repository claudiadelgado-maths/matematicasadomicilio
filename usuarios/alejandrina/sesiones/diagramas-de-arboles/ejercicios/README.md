# Ejercicios de Diagramas de árboles

Contenedor de prácticas exclusivas de esta sesión.

## Contenido

- `construye-el-arbol/`: módulo publicado con tres generadores de práctica para completar, leer y construir árboles.

Los ejercicios utilizan el generador compartido `../arboles.mjs`. No dupliques la lógica matemática dentro de otro componente de la sesión.
