# Usuarios

Índice de espacios personalizados. Cada usuario vive en una carpeta propia con metadatos, contexto y sesiones.

No coloques información sensible en HTML, JSON o commits. El índice solo debe mostrar usuarios autorizados. Las sesiones y recursos específicos permanecen dentro del usuario correspondiente.

Para una modificación aislada, entra en la carpeta del usuario, lee su README y evita tocar otros espacios.

## Espacios actuales

- `jose/`: tablero personal de tareas con almacenamiento local.
- `alejandrina/`: sesiones personalizadas de estadística y probabilidad.
- `andres/`: sesiones de preparatoria; Porcentajes está publicado con teoría, ejercicios, calculadoras y juego.
