# ¿Cuánto mide? ¿Cuánto pesa?

Sesión infantil de una sola página para distinguir peso y altura mediante exploración.

## Interacción

Luca elige un animal y después una herramienta. La báscula revela un peso y la regla revela una altura. Inmediatamente aparece una pregunta de tres opciones sobre el dato que acaba de observar. El banco contiene ocho animales en dos conjuntos; «Nuevos ejercicios» alterna el conjunto disponible y reinicia la exploración.

Los dibujos de las herramientas son SVG en línea; los controles siguen siendo botones HTML accesibles mediante teclado y tacto.

## Pruebas

- Cada animal puede explorarse con ambas herramientas.
- Las preguntas y respuestas cambian con la selección.
- Acierto y error incluyen mensajes textuales.
- No hay desplazamiento horizontal a 360 px.
