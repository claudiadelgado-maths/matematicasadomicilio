# Casillero de Luca

Espacio infantil de Luca dentro del salón de Claudia. El alumno utiliza el ID global `luca-claudia` y la ruta local `luca`.

## Contenido

Contiene exactamente tres sesiones publicadas:

1. Consigue el cambio.
2. ¿Cuánto mide? ¿Cuánto pesa?
3. Las horas.

Cada sesión funciona en una sola página, contiene su interacción dentro del módulo y evita subcomponentes vacíos.
