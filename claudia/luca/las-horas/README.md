# Las horas

Sesión infantil de una sola página sobre horas exactas en un reloj de doce horas.

## Interacción

La manecilla se mueve al tocar un número o cualquier punto del reloj. Los números son botones HTML para conservar navegación por teclado. Los retos progresan desde colocar una hora hasta sumar o restar pocas horas dentro del ciclo de doce. Dos bancos de seis retos se alternan mediante «Nuevos ejercicios».

No aparecen minutos, segundos, medias horas, cuartos, AM/PM ni formato de veinticuatro horas.

## Pruebas

- Los doce números mueven la manecilla.
- Tocar el círculo selecciona la hora más cercana.
- Los seis retos validan la hora y permiten continuar.
- El reloj cabe y responde correctamente a 360 px.
