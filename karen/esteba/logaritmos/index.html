Logaritmos

Un logaritmo responde una pregunta concreta: ¿a qué exponente debemos elevar la base para obtener cierto número?

log
  • Teoría
  • Ejercicios

Parte 1

Teoría

La forma exponencial y la forma logarítmica expresan la misma relación con distinto orden.

Equivalencia fundamental

a^b=c\quad\Longleftrightarrow\quad\log_a(c)=b

Se lee: “el logaritmo en base a de c es b”. Esto significa que a elevada a b produce c.

Las partes

Base
a, el número que se eleva. Debe cumplir a>0 y a\neq1.
Argumento
c, el resultado de la potencia. Debe ser positivo.
Resultado
b, el exponente que estamos buscando.

Ejemplo directo

2^3=8\quad\Longleftrightarrow\quad\log_2(8)=3

La pregunta “¿a qué potencia elevamos 2 para obtener 8?” tiene respuesta 3.

De logaritmo a potencia

\log_5(125)=3\quad\Longleftrightarrow\quad5^3=125

Convertir la expresión permite comprobar el resultado de inmediato.

Valores básicos

\log_a(1)=0\qquad\log_a(a)=1

Esto ocurre porque a^0=1 y a^1=a.

Ruta de trabajo

Para calcular un logaritmo sencillo, conviértelo en una ecuación exponencial y busca una potencia conocida. No necesitas memorizar una lista aislada si puedes responder qué exponente produce el argumento.

Parte 2

Ejercicios

Convierte cada expresión antes de calcular.

  1. Convierte 3^4=81 a forma logarítmica.

    Ver respuesta
    \log_3(81)=4.

  2. Convierte \log_2(32)=5 a forma exponencial.

    Ver respuesta
    2^5=32.

  3. Calcula \log_{10}(1000).

    Ver respuesta
    10^3=1000, así que el resultado es 3.

  4. Calcula \log_4(64).

    Ver respuesta
    4^3=64, por tanto \log_4(64)=3.

  5. Identifica base, argumento y resultado en \log_7(49)=2.

    Ver respuesta
    Base 7, argumento 49 y resultado 2. La comprobación es 7^2=49.
