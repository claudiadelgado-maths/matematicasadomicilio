# Gráficas de barras en ventas

Sesión explicativa de Alex con Erick Chan. Enseña a leer gráficas de barras y a convertir una comparación visual en una conclusión útil.

La sesión contiene exactamente tres ejemplos desarrollados:

1. ventas semanales de audífonos;
2. comparación mensual de teléfonos;
3. unidades vendidas frente a ingresos de accesorios.

Las gráficas son SVG accesibles e integradas en la página. Las operaciones se renderizan con KaTeX mediante `../../matematicas.js`. No hay componentes opcionales externos; por eso todos los valores de `componentes` en `sesion.json` permanecen en `false`.

Comprueba que las etiquetas de las gráficas sigan legibles, que los SVG no generen desplazamiento horizontal y que la explicación mantenga tres ejemplos si se actualiza el contenido.
