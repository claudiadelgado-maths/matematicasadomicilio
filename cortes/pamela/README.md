# Casillero de Pamela

Casillero de secundaria de Pamela. Contiene una sesión visual del teorema de Pitágoras con un ejercicio dinámico que conserva el mismo triángulo, genera valores nuevos y acepta respuestas enteras o raíces exactas.

El índice obtiene las sesiones publicadas desde el catálogo académico. Ejecuta `npm run catalogo` y `npm run validar` después de modificar sus metadatos.
