# Teorema de Pitágoras

Sesión de secundaria de Pamela con explicación visual y un ejercicio dinámico integrado.

## Interacción

- El triángulo mantiene la misma orientación y actualiza sus etiquetas.
- `Nuevos valores` selecciona un problema validado de un banco local.
- La hipotenusa siempre es el lado `c` y siempre es mayor que los catetos conocidos.
- La respuesta puede introducirse como entero o mediante el botón `Usar √`, que muestra una casilla para el radicando.
- Los resultados irracionales se eligen con radicandos sin factores cuadrados, de modo que la forma `√n` ya está simplificada.
- No se guardan datos ni progreso en el navegador.

La interacción vive en `ejercicio.js`. Comprueba teclado, mensajes de estado, generación repetida y diseño móvil después de modificarla.
