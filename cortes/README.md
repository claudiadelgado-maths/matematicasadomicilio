# Salón de Cortés

Perfil público de Cortés y entrada a los casilleros de Pedro y Pamela. Los datos comerciales y académicos se administran en `maestro.json`; las relaciones con alumnos y sesiones se generan desde sus metadatos.

La imagen pública está en `/recursos/imagenes/cortes.jpg`. El estilo del salón toma su identidad de la ilustración: tonos oscuros con acentos cian, magenta y amarillo.

## Enfoque

- Diseño y dibujo explicados mediante práctica compartida.
- Referencias visuales y de cultura pop.
- Pedro: nivel universitario y teoría del color.
- Pamela: nivel secundaria y geometría aplicada.

Después de modificar el perfil, alumnos o sesiones, ejecuta `npm run catalogo` y `npm run validar`.
