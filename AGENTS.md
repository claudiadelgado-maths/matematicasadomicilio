# Instrucciones para agentes

Lee `README.md` y la documentación del área que vayas a modificar.

- Conserva el sitio estático y sin dependencias innecesarias.
- Usa rutas relativas y URLs públicas con directorio e `index.html`.
- Mantén navegación, logotipo, pie y botón flotante coherentes.
- No edites módulos ajenos a la tarea salvo que una dependencia compartida lo exija.
- Si cambias un recurso compartido, revisa todas sus páginas consumidoras.
- Cada módulo concreto debe conservar su README y JSON sincronizados con el contenido real.
- No muestres componentes opcionales vacíos.
- Ejecuta `npm run catalogo` y `npm run validar` antes de terminar.
- Comprueba móvil, escritorio, teclado, consola y enlaces cuando el cambio afecte la interfaz.
