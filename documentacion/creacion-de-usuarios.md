# Crear un usuario

Ruta: `/usuarios/[slug]/`.

Incluye `index.html`, `README.md`, `usuario.json` y `sesiones/`. Evita datos sensibles: usa solo el nombre o identificador autorizado y contenido educativo necesario.

El índice del usuario muestra sus sesiones reales. Si se necesita almacenamiento local, documenta claves y comportamiento de borrado. Añade el acceso en `/usuarios/` únicamente cuando corresponda.
