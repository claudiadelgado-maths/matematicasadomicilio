# Crear una explicación o demostración

Una explicación vive en `[tema]/explicacion/`. Si un tema necesita varias explicaciones independientes, usa `[tema]/explicaciones/[slug]/`. Una demostración vive en `[tema]/demostraciones/[slug]/`.

Incluye `index.html` y `README.md`. Añade CSS o JavaScript local únicamente si existe comportamiento propio. La lectura debe tener ejemplos claros, jerarquía de títulos, notación accesible y navegación de regreso al tema.

Una demostración interactiva debe funcionar con teclado, explicar qué cambia y ofrecer una representación textual cuando la gráfica o el dibujo sea esencial.
