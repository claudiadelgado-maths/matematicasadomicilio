# Crear un ejercicio

Ruta: `[tema]/ejercicios/[slug]/` o `[sesion]/ejercicios/[slug]/`.

Archivos mínimos: `index.html`, `README.md`, `ejercicio.json`; añade `script.js` y `estilos.css` para interacción propia.

El ejercicio debe indicar la consigna, validar entradas, permitir reintentar y dar retroalimentación comprensible. No reveles solo “correcto/incorrecto” si una explicación breve puede orientar. Las preguntas aleatorias deben conservar dificultad y respuestas válidas.

Prueba teclado, móvil, valores vacíos, respuestas incorrectas, generación repetida y reinicio.
