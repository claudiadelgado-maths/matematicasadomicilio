# Crear una sesión

Ruta: `/usuarios/[usuario]/sesiones/[slug]/`.

Incluye `index.html`, `README.md`, `sesion.json` y solo los componentes disponibles. Cada ejercicio, juego o calculadora complejo usa una subcarpeta propia.

El JSON debe describir objetivo, usuario, conocimientos previos, estado, ruta y componentes. El índice enlaza al usuario y a cada componente. Comprueba que el contenido no quede accesible mediante una tarjeta vacía o una ruta incorrecta.
