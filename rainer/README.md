# Salón de Rainer

Perfil público de Rainer y acceso a los casilleros universitarios de Sofía y Mateo.

`maestro.json` es la fuente de verdad para su ubicación, disponibilidad, tarifa, presentación y metodología. El salón reutiliza el componente académico compartido.

## Verificación

- Aparece en Salones y Precios.
- Publica una sesión de 80 minutos por 750 MXN; la restricción universitaria se comunica únicamente mediante la disponibilidad.
- La disponibilidad indica «Solo para alumnos universitarios».
- Contiene exactamente dos casilleros, ordenados por la fecha reciente de sus sesiones.
