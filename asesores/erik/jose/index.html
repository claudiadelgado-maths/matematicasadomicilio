Definir antes de comenzar

Definir una tarea significa explicar claramente qué se debe hacer, cómo se realizará, qué materiales o herramientas se necesitan y, cuando corresponda, cuándo debe terminarse.

Una tarea como “barrer” puede parecer evidente, pero al definirla podemos agregar detalles importantes: qué espacio se limpiará, qué herramienta se utilizará, cómo se recogerá la basura y a qué hora debe estar terminada.

Este procedimiento también puede utilizarse para actividades del hogar, proyectos, trabajos y tareas escolares. Definir correctamente una actividad ayuda a comprenderla, recordarla y realizarla con mayor facilidad.
