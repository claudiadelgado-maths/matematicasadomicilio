# Conversor eléctrico

Página de Electricidad 1 para Raúl. Explicación e interacción: `../../recursos/conversor.mjs`. Importa `../../recursos/electricidad.css`, `ui.mjs` y `motor.mjs`; no altera recursos globales. Lee el README de la sesión y AVANCE.md para retomar el trabajo.

Navegación relativa a página anterior y siguiente; el conversor cierra con regreso a Raúl. El estado de ejercicios solo vive en memoria. Comprobar teclado, tacto, móvil, consola, enlaces y reinicio de actividad. Ejecutar las pruebas del motor, npm run catalogo y npm run validar desde la raíz.

Incluye un ejemplo cotidiano ilustrado y una pregunta con respuesta completa antes de la actividad. La navegación superior de migas y temas se retiró por petición del usuario.
