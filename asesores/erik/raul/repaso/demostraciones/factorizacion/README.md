# Factorización

Cierre de Repaso de Raúl, salón de Erik. Presentación interactiva sin evaluación: árbol de factores, distintos caminos y factores comunes. Aquí termina la sesión.

Recursos comunes en `../../recursos/cierre/`: motor de generación y factores, representación matemática y estilos. Usa el motor racional de Repaso sin modificarlo. Ratón, táctil y teclado. Los ejemplos son modelos con condiciones explícitas. No guarda respuestas.

Ejecutar `npm run catalogo`, `npm run validar` y `node asesores/erik/raul/repaso/pruebas/cierre.test.mjs`. Revisar reinicios, resultados, ramas, pantallas pequeñas, teclado y enlaces.
