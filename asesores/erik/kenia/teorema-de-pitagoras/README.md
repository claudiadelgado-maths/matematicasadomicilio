# Teorema de Pitágoras · Kenia · Erik

Sesión corta publicada el 2026-09-28. Menú, explicación de tres pasos, cuatro ejercicios por ronda y juego de tres versiones de cuatro niveles (12 situaciones). La explicación permite revelar sustitución, operación y raíz. Práctica con ternas pitagóricas variables y mezcla de catetos e hipotenusa.

El juego elige una versión aleatoriamente al entrar; al volver a jugar elige otra de las dos restantes. Cada versión contiene cuatro situaciones fijas con incógnitas variadas. Solo una respuesta correcta desbloquea Continuar. Reintentos sin penalización, ayuda opcional y procedimiento al acertar. Sin tiempo ni persistencia de datos. Doce ilustraciones SVG con variantes de árboles, jardines en vista superior, escaleras, tienda, mástil y rampas; medidas en tarjetas, incógnita morada y ángulo recto visible. Dibujos esquemáticos, no a escala. Entradas aceptan número decimal o fracción equivalente positiva.

Recursos exclusivos en recursos/: modelo.mjs (matemáticas y 12 misiones), app.mjs (interacciones), figuras.mjs (ilustraciones del juego), sesion.css (diseño), modelo.test.mjs (verificaciones). Cada módulo conserva HTML, CSS, README y JSON. KaTeX 0.18.1 por CDN; el texto matemático alternativo permanece si no carga. No se modifican recursos globales.

Verificar: node --test asesores/erik/kenia/teorema-de-pitagoras/recursos/modelo.test.mjs; npm run catalogo; npm run validar. Probar escritorio, móvil, teclado, navegación, errores y los cuatro niveles de cada versión. Mantener identidad, rutas y metadatos al sustituir la carpeta completa.
