# Reconoce los tres lados

Paso 2 de 10 de Funciones trigonométricas para Kenia. Entrada: index.html. Conserva la ruta de su JSON, el enlace de inicio y la navegación anterior/continuar.

Comparte `../../recursos/sesion.css`, `../../recursos/sesion.mjs` y `../../recursos/modelo.mjs` dentro de esta sesión. La entrada local estilos.css importa la hoja compartida. KaTeX 0.18.1 y marca/navegación global mediante rutas relativas. Lee también el README de la sesión antes de modificar el contrato matemático o una interacción.

No almacena ni envía calificaciones. Prueba ratón, arrastre, clic, táctil mediante eventos de puntero y teclado; respuestas vacías, incorrectas y correctas; móvil, consola y enlaces. Las fracciones numéricas equivalentes se comparan exactamente. Las casillas de tarjetas se rellenan al arrastrar o al seleccionar una tarjeta y pulsar la casilla.
