# Práctica de despejes

Ejercicio interactivo de la sesión **Despejes lineales** de Kenia.

- Cada serie presenta 4 retos simultáneos: despeje básico, signos, respuesta fraccionaria y combinación de fracciones.
- Cuatro variantes por categoría producen 16 ecuaciones de la forma `Ax + B = C`.
- Las ecuaciones y los procedimientos se renderizan con KaTeX.
- Las respuestas enteras usan una casilla sencilla.
- Las respuestas fraccionarias usan dos casillas apiladas: numerador arriba y denominador abajo.
- Acepta fracciones equivalentes, normaliza signos y compara el resultado de manera exacta.
- Cada tarjeta ofrece retroalimentación independiente y un procedimiento consultable después del intento.
- **Nueva serie** sustituye los cuatro retos sin recargar la página y reinicia el progreso.

La hoja `estilos.css` pertenece únicamente a esta práctica y mantiene las ecuaciones y las entradas fraccionarias estables en móvil.

Ruta pública: `/erik/kenia/despejes-lineales/ejercicios/practica-de-despejes/`.
