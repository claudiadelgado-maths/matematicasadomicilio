Reparte en partes iguales

Si tres veces x vale 12, cada x vale 4.

3x significa tres veces x. Divide ambos lados entre el número que multiplica a la incógnita.

Mira qué cambia

  1. Tres grupos iguales suman 12.

    3x=12

  2. Dividimos los dos lados entre 3.

    \frac{3x}{3}=\frac{12}{3}

  3. Queda un solo grupo.

    x=4
