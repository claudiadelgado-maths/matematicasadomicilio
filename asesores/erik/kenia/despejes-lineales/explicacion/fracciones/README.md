# Deshaz una multiplicación por una fracción

Paso 7 de 9 de la explicación de Despejes lineales para Kenia.

Objetivo: Multiplica por su recíproco para obtener 1.

Entrada: index.html. Comparte ../recorrido.css y ../recorrido.js con el resto de pasos. Usa KaTeX 0.18.1, recursos globales y enlaces relativos. No guarda progreso. Conserva los enlaces anterior, inicio y continuar; el último paso enlaza a los ejercicios existentes.

Prueba: ejemplo, respuestas correcta e incorrecta, teclado y móvil. Mantén el contrato matemático: misma operación en ambos lados; nunca dividir entre cero.
