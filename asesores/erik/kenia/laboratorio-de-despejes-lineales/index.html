Cómo jugar

Toca un bloque y elige una operación. Para combinar, selecciona las dos cantidades. Toca otra vez un bloque para quitar su selección. Puedes acumular operaciones y combinar cuando quieras. Un bloque puede regresar mediante la operación inversa. Para cambiar el orden, selecciona bloques de dos términos distintos del mismo miembro y toca «Cambiar orden». Los factores solo pueden cruzar si afectan a todo el miembro; las sumas se conservan entre paréntesis.

“Pasar al otro lado” resume aplicar la operación inversa a ambos miembros: la igualdad se conserva.

El número y la x se seleccionan por separado. Si eliges x para sumar o restar, viaja su término completo. Para dividir por x debe estar garantizado que x ≠ 0; verás esa condición junto al visor.

Deshacer retrocede un paso. Reiniciar recupera la misma ecuación.
