# Práctica de sucesiones aritméticas

Práctica generativa basada en una sola sucesión por ronda.

Cada nueva ronda construye cinco términos desde un par (a₁, d) y plantea seis comprobaciones:

1. primer término;
2. diferencia común;
3. tercer término;
4. quinto término;
5. fórmula general;
6. término de una posición entre 8 y 12.

La opción **Incluir sucesiones decrecientes** permite trabajar con diferencias negativas. La fórmula se completa mediante un operador y una magnitud separados para mostrar aₙ = a₁ − (n − 1)|d| en lugar de una suma con número negativo.

Los aciertos se cuentan una sola vez por pregunta. Una respuesta incorrecta conserva la misma sucesión y ofrece una pista asociada al concepto. El botón de nueva sucesión evita repetir inmediatamente el mismo par (a₁, d).
