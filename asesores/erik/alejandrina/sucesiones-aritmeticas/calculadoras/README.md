# Analizador de sucesiones

Herramienta para introducir una lista y determinar si su diferencia es constante.

## Comportamiento

- acepta números separados por comas, espacios o punto y coma;
- exige al menos tres términos;
- calcula y muestra todas las diferencias consecutivas;
- acepta enteros y decimales finitos;
- identifica sucesiones crecientes, decrecientes y constantes;
- cuando la sucesión es aritmética, muestra a₁, d, cantidad de términos, fórmula estructural y forma simplificada;
- cuando no es aritmética, conserva las diferencias visibles y explica por qué no son constantes.

La forma principal siempre es aₙ = a₁ + (n − 1)d. Si d es negativa se presenta como resta. La forma simplificada es secundaria.
