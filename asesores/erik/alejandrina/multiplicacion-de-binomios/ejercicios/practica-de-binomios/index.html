Ejercicio

Avanza una idea a la vez: primero distribuye, después escribe la distribución completa y al final simplifica el resultado.

  1. 1Distribuir
  2. 2Organizar
  3. 3Simplificar
1

Primera fase

Distribuye un término

Multiplica el término exterior por cada término del paréntesis.

Reto 1

Completa los dos coeficientes. Usa el selector para decidir si el término con x se suma o se resta.

x² x
0 resueltos

Así se distribuye

2

Segunda fase

Escribe la distribución

Todavía no multipliques. Solo muestra qué término multiplica a cada paréntesis.

Reto 1

Repite el segundo binomio en ambos paréntesis. Los desplegables sirven para conservar cada signo.

x ( x ) ( x )
0 resueltos

Distribución correcta

3

Tercera fase

Simplifica el resultado

Realiza la distribución y reúne los dos términos que contienen x.

Reto 1

Completa los tres coeficientes y elige los dos signos del trinomio.
