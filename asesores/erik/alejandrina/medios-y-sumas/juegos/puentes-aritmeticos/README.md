# Puentes aritméticos

Construye caminos con saltos iguales.

Juego independiente de medios aritméticos, con seis retos. Avanza al resolver o revisar cada procedimiento. Finaliza tras completar todos los retos; el reinicio genera nuevos valores. Sin cronómetro, almacenamiento ni dependencia de color. La práctica ordinaria de otras páginas no cuenta como un juego adicional.

Recursos de esta sesión: motor.mjs, ui.mjs, actividad.mjs y sesion.css, bajo ../../recursos/. Verificar teclado, móvil, escritorio, valores vacíos, incorrectos, fracciones y nueva generación. Nivel: primero de preparatoria. Formato tomado de las sesiones de Raúl; no depende de ellas.
