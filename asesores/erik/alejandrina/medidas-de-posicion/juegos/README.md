# Juegos de Medidas de posición

Contenedor de juegos exclusivos de esta sesión.

## Juegos actuales

- `recorrido-de-posiciones/`: **El taller del corte exacto**, juego publicado para ubicar cuartiles, deciles, percentiles y mediana sobre una cinta del 0% al 100%.

El juego trabaja equivalencias porcentuales exactas. No calcula medidas a partir de conjuntos de datos.
