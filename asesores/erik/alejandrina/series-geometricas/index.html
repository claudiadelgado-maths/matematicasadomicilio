Mi mapa de fórmulas

Un término

aₙ = a₁ × rⁿ⁻¹

n cuenta términos; n−1 cuenta saltos.

El primer término

a₁ = aₙ / rⁿ⁻¹

Para dividir, r debe ser distinta de cero.

La razón positiva

r = raíz de índice n−1 de (aₙ/a₁)

Con términos positivos y n > 1. Si no se exige r positiva, revisa también el signo.

Dos términos conocidos

a_q / a_p = r^(q−p)

Con p < q y aₚ distinto de cero. La distancia entre posiciones determina el exponente.

La suma de n términos

Sₙ = a₁(rⁿ−1)/(r−1)

Si r = 1, usa Sₙ = n × a₁.

Insertar k medios positivos

r = raíz de índice k+1 de (B/A)

Entre extremos positivos A y B: k+2 términos y k+1 saltos.
