📖 Explicación · Sesión 2

Encuentra el elemento que falta

No necesitas memorizar fórmulas sueltas. Todas nacen de una sola relación y cada dato conocido te dice qué camino seguir.

Nuestro punto de partida
a_n=a_1+(n-1)d

Primer término + número de saltos × tamaño de cada salto.

Paso 1 · Lee los símbolos

Una fórmula, cuatro elementos

a₁ es el punto de partida, d es el salto constante, n es la posición y aₙ es el valor que ocupa esa posición.

Desde la posición 1 hasta la posición n hay n − 1 saltos. Esa idea explica toda la fórmula.

a₁
Primer término
d
Diferencia común
n
Posición
aₙ
Término en la posición n

Paso 2 · Elige la incógnita

Las cuatro rutas

Mira qué dato falta y usa la tarjeta correspondiente.

aₙ

Encontrar un término

a_n=a_1+(n-1)d

Úsala cuando conoces el primer término, la diferencia y la posición.

a₁

Encontrar el primer término

a_1=a_n-(n-1)d

Si ves la lista, a₁ es el primer valor. Si solo conoces otro término, despeja con esta fórmula.

d

Encontrar la diferencia

d=\frac{a_i-a_j}{i-j},\quad i\ne j

Sirve con dos términos conocidos y sus posiciones. El orden debe ser el mismo arriba y abajo.

n

Encontrar una posición

n=\frac{a_n-a_1}{d}+1,\quad d\ne0

El resultado debe ser un entero positivo para representar una posición de la sucesión.

Zoom sobre d

La diferencia cuenta los saltos

Con términos consecutivos basta una resta. Con términos separados, divide el cambio de valores entre el cambio de posiciones.

👣

Términos consecutivos

d=a_{k+1}-a_k

Ejemplo: entre 18 y 23, d = 23 − 18 = 5.

🪜

Términos separados

d=\frac{a_i-a_j}{i-j}

Si intercambias i y j, intercambia también los términos del numerador.

🎯

Desde a₁ hasta aₙ

d=\frac{a_n-a_1}{n-1},\quad n\ne1

Es el mismo razonamiento usando la posición 1 como referencia.

Lee el signo

d también indica la dirección

d > 0📈

Creciente

Cada término es mayor que el anterior.

d < 0📉

Decreciente

Cada término es menor que el anterior.

d = 0➡️

Constante

Todos los términos tienen el mismo valor.

Ejemplo completo

Conocemos a₄ = 23 y a₁₀ = 53

Primero hallamos d. Después reconstruimos a₁ y ya podemos encontrar cualquier término o posición.

  1. 1

    Calcula d

    d=\frac{53-23}{10-4}=5
  2. 2

    Calcula a₁

    a_1=23-(4-1)5=8
  3. 3

    Escribe la fórmula

    a_n=8+(n-1)5
  4. 4

    Encuentra la posición de 68

    n=\frac{68-8}{5}+1=13

Antes de terminar

Tres comprobaciones rápidas

🔁

Mismo orden

En la fórmula de d, si arriba haces aᵢ − aⱼ, abajo debe ser i − j.

🚫

No dividas entre cero

Necesitas posiciones distintas para calcular d y una diferencia no nula para despejar una posición única.

✅

Sustituye para verificar

Coloca tu resultado en la fórmula original. Si recuperas el término conocido, el despeje funciona.
