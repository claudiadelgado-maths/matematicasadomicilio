# Fórmulas de sucesiones aritméticas · Sesión 2

Segunda sesión del bloque de sucesiones para Alejandrina. Parte de `aₙ = a₁ + (n − 1)d` y enseña a elegir y despejar la fórmula adecuada para encontrar `a₁`, `d`, `n` o `aₙ` cuando se conocen los demás datos.

## Alcance

- cálculo de un término con `a₁`, `d` y `n`;
- cálculo de `a₁` a partir de un término conocido;
- cálculo de `d` usando dos términos y sus posiciones;
- cálculo de la posición `n` de un término;
- interpretación del signo de `d`;
- comprobación de condiciones como `i ≠ j`, `n ≠ 1` y `d ≠ 0`.

No introduce suma de términos, series, recurrencias ni progresiones geométricas.

## Componentes

- `explicacion/`: recorrido progresivo con despejes, condiciones y un ejemplo completo.
- `ejercicios/`: tandas generativas de seis ejercicios con respuestas enteras.
- `calculadoras/`: tres herramientas para encontrar `d`, `n` o `aₙ`, con sustitución en LaTeX.
- `juegos/`: trivia dinámica de doce retos respondidos mediante botones.

## Recursos compartidos

- `formulas.mjs`: operaciones, fracciones, generación y renderizado matemático.
- `formulas.css`: sistema visual local de la sesión y sus componentes.

Cada componente conserva su README y JSON. Los datos dinámicos se generan de forma que los ejercicios evaluables tengan solución entera.
