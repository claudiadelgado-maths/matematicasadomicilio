# Práctica · Fórmulas de sucesiones aritméticas

Práctica generativa de seis ejercicios por tanda. Cada ejercicio pide encontrar un dato distinto:

1. un término `aₙ`;
2. el primer término `a₁`;
3. la diferencia desde `a₁` y `aₙ`;
4. la diferencia desde dos términos cualesquiera;
5. la posición `n`;
6. un término a partir de otro término conocido.

Las sucesiones se generan desde valores enteros `(a₁, d)` y posiciones enteras, por lo que todas las respuestas evaluadas son enteras. Una respuesta incorrecta conserva el problema y ofrece una pista. Los aciertos se cuentan una sola vez. **Nueva tanda** genera seis problemas diferentes y reinicia la puntuación de la tanda.
