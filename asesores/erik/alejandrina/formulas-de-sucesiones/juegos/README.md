# Trivia de las fórmulas perdidas

Juego de doce preguntas para repasar cómo encontrar los elementos de una sucesión aritmética.

## Reglas

- cada pregunta presenta cuatro botones;
- al elegir un botón, la respuesta se comprueba inmediatamente;
- un acierto suma 10 estrellas;
- una respuesta incorrecta muestra la opción correcta y una explicación breve;
- **Siguiente reto** avanza hasta completar las doce preguntas;
- la fórmula base `aₙ = a₁ + (n − 1)d` permanece visible como recordatorio durante toda la partida;
- **Jugar otra vez** reinicia la puntuación y cambia el orden, la selección de retos y los valores numéricos.

Cada partida conserva las cuatro fórmulas esenciales y toma ocho retos de un conjunto dinámico de interpretación, condiciones de uso y cálculos breves de `a₁`, `d`, `n` y `aₙ`. No depende de tiempo, sonido ni únicamente del color.
