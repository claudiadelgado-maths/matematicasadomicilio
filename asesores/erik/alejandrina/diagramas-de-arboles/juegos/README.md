# Juegos de Diagramas de árboles

Contenedor de juegos exclusivos de esta sesión.

## Juegos actuales

- `elige-el-camino/`: **El laberinto infinito**, juego publicado en el que un diagrama de árbol funciona como mapa y cada puerta representa una rama.

El juego trabaja únicamente la lectura estructural del árbol. No introduce probabilidades, cantidades de una colección ni puntuaciones.
