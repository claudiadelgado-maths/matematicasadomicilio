Tus fórmulas a la mano

Área: superficie interior. Perímetro: suma de las orillas.

Rectángulo

b: base · h: altura

A = b × h

P = 2b + 2h = 2(b + h)

Cuadrado

A = l²

P = 4l

Sus cuatro lados son iguales.

Triángulo

b: base · h: altura

A = b × h ÷ 2

P = b + L₁ + L₂

En el isósceles, las marcas señalan los dos lados iguales. La altura es perpendicular a la base.

Trapecio

A = (B + b) × h ÷ 2

P = B + b + L₁ + L₂

B: base mayor · b: base menor · h: altura. Los otros dos lados son L₁ y L₂.
