# Casillero de Pedro

Casillero universitario de Pedro con cuatro sesiones secuenciales de teoría del color: modelos, propiedades y círculo cromático, armonías y temperaturas, y contraste en contexto.

El índice obtiene las sesiones desde `recursos/datos/academia.json`; no agregues tarjetas manualmente. Conserva los metadatos y el contenido sincronizados y ejecuta `npm run catalogo` y `npm run validar` después de cualquier cambio.
