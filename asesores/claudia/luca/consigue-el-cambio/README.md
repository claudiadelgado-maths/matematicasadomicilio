# Consigue el cambio

Sesión infantil de una sola página para introducir suma y resta mediante compras muy sencillas.

## Interacción

El niño elige un producto, observa el precio y el dinero entregado, y selecciona el cambio correcto. La respuesta ofrece texto, icono y color; al acertar se habilita una nueva compra. El banco local contiene nueve productos organizados en tres conjuntos. «Nuevos ejercicios» cambia el conjunto completo sin aumentar la dificultad.

## Pruebas

- Los tres productos actualizan precio, pago y respuestas.
- Una respuesta incorrecta permite volver a intentarlo.
- Una respuesta correcta actualiza el contador y ofrece otra compra.
- Todos los controles funcionan con teclado y a 360 px de ancho.
