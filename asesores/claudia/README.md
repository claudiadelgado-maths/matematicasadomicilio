# Salón de Claudia

Perfil público de Claudia y punto de entrada a los casilleros de sus alumnos.

## Fuente de verdad

`maestro.json` contiene su presentación, ubicación, modalidad individual, disponibilidad y tarifa. El salón y los catálogos de Salones y Precios se generan con los componentes académicos compartidos; no deben duplicarse manualmente.

## Verificación

- Claudia aparece como asesora activa en `/asesores/`.
- La portada publica una sesión de 60 minutos por 120 €.
- El botón de contacto prepara un mensaje dirigido a Claudia.
- El casillero de Luca aparece únicamente dentro de este salón.
