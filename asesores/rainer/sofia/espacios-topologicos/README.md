# Espacios topológicos

Primera sesión del recorrido de Sofía. Desarrolla la intuición y la definición axiomática, vocabulario básico, un método de verificación, ejemplos finitos e infinitos, comparación de topologías, una demostración y seis ejercicios resueltos.

Las demostraciones y soluciones están implementadas con `<details>` y `<summary>` nativos: permanecen ocultas al inicio, funcionan con teclado y no requieren JavaScript. La sesión enlaza directamente con «Interior, clausura y frontera» para continuar el recorrido.
