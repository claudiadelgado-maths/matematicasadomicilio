# Casillero de Alex

Casillero provisional del único alumno de Erick Chan. Reúne una sesión interactiva de estadística sobre gráficas de barras aplicada a ventas y tecnología.

El nombre `Alex` se usa de forma provisional porque todavía no se proporcionó el nombre del alumno. Si se reemplaza, actualiza `usuario.json`, el contenido visible, la ruta si corresponde y todos los metadatos de sus sesiones; después ejecuta `npm run catalogo` y `npm run validar`.
