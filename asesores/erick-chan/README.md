# Salón de Erick Chan

Perfil público de Erick Chan y entrada a los casilleros de sus alumnos. La información profesional, ubicación, modalidad, disponibilidad y precio se administra en `maestro.json`; los alumnos se relacionan mediante su propio `usuario.json`.

La fotografía pública es `/asesores/erick-chan/recursos/erick-chan.jpg`. El campo `imagenAjuste: "contain"` es intencional: la ilustración debe mostrarse completa y no debe recortarse para llenar el marco.

## Identidad de las sesiones

- Estadística aplicada a ventas, tecnología y trabajo.
- Explicación basada en contextos reales y decisiones útiles.
- Tres ejemplos desarrollados por sesión.
- Diseño sobrio con acentos turquesa y naranja.

Después de cambiar el maestro o sus alumnos, ejecuta `npm run catalogo` y `npm run validar`.
