# Recursos compartidos de asesores

Estos archivos pertenecen únicamente al área académica y evitan repetir implementaciones idénticas:

- `js/perfil-asesor.js`: carga el perfil y los alumnos de un asesor;
- `js/alumno.js`: carga los datos y sesiones publicadas de un alumno;
- `js/matematicas.js`: representa las expresiones marcadas con `data-math` cuando KaTeX está disponible.

No agregues aquí lógica exclusiva de una sesión, ejercicio, juego o calculadora. Esos comportamientos permanecen junto a su página. La navegación superior y los controles flotantes pertenecen a `/recursos/js/navegacion.js`.
