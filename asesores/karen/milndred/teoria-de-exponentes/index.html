Teoría de exponentes

Una forma corta y ordenada de escribir multiplicaciones donde el mismo factor se repite.

aⁿ
  • Teoría
  • Ejercicios

Parte 1

Teoría

Primero observamos la multiplicación completa; después aprendemos a comprimirla con una potencia.

De multiplicación repetida a potencia

2\times2\times2\times2=2^4

El número 2 aparece como factor cuatro veces. La notación 2^4 expresa exactamente esa repetición.

Las tres partes

Base
Es el factor que se repite. En 2^4, la base es 2.
Exponente
Indica cuántas veces usamos la base como factor. Aquí es 4.
Potencia
Puede nombrar toda la expresión o su resultado: 2^4=16.

Ejemplo aritmético

3\times3\times3=3^3=27

La base es 3, el exponente es 3 y el valor de la potencia es 27.

También funciona con letras

x\cdot x\cdot x=x^3

No necesitamos conocer el valor de x. Solo registramos que el mismo factor aparece tres veces.

Otro paso algebraico

a\cdot a\cdot a\cdot a\cdot a=a^5

La base es a y el exponente 5. El exponente no es un factor adicional.

Observación importante

El exponente cuenta factores, no multiplicaciones escritas. En 5^3 aparecen tres factores iguales: 5\cdot5\cdot5. Hoy nos concentramos en leer y construir potencias; las leyes de exponentes se estudiarán después.

Parte 2

Ejercicios

Avanza desde números hasta letras. Intenta cada ejercicio antes de abrir la respuesta.

  1. Escribe como potencia: 4\times4\times4\times4\times4.

    Ver respuesta
    4^5. La base 4 aparece cinco veces.

  2. Desarrolla la potencia 6^3 como multiplicación y calcula su valor.

    Ver respuesta
    6\times6\times6=216.

  3. En 7^4, identifica base y exponente.

    Ver respuesta
    Base: 7. Exponente: 4.

  4. Escribe de forma abreviada: m\cdot m\cdot m\cdot m.

    Ver respuesta
    m^4.

  5. Completa: y^6=y\cdot\square\cdot\square\cdot\square\cdot\square\cdot\square.

    Ver respuesta
    Todos los espacios llevan y; deben aparecer seis factores iguales.
