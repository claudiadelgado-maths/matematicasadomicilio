# Casillero de Kevin

Casillero universitario con tres sesiones: conjuntos, límites y derivada como límite. Los temas construyen bases de Cálculo I antes de introducir reglas mecánicas, pero cada sesión funciona como un módulo atómico e independiente.

Las tres sesiones comparten sesiones.css únicamente dentro del casillero y usan el controlador de fórmulas interactivas del salón de Elizabeth. Cada una incluye explicación conceptual, fórmulas o estrategias revelables, método, cinco ejemplos desarrollados y seis ejercicios con respuesta.

No hay botones de continuación ni enlaces directos entre sesiones. La única salida contextual de cada sesión vuelve al casillero de Kevin.
