# Casillero de Jimena

Casillero universitario con dos sesiones de cálculo avanzado: derivada paramétrica e integral de curva.

Las dos sesiones comparten sesiones.css únicamente dentro del casillero y usan el controlador de fórmulas interactivas del salón de Elizabeth. Cada una incluye explicación conceptual, fórmulas revelables, método, cinco ejemplos desarrollados y seis ejercicios con respuesta.

Cada sesión es un módulo atómico. No presenta enlaces directos ni botones de continuación hacia la otra sesión; su única salida contextual vuelve al casillero de Jimena.
