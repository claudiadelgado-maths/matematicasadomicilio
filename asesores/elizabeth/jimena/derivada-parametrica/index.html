Derivada paramétrica

Una curva paramétrica describe las coordenadas mediante un tercer valor. La pendiente relaciona cómo cambian ambas coordenadas respecto a ese parámetro.

r(t)
  • Teoría
  • Ejemplo guiado
  • 2 resueltos

Parte 1

Teoría

La curva se escribe como x=x(t) y y=y(t).

Primera derivada

\frac{dy}{dx}=\frac{dy/dt}{dx/dt},\qquad \frac{dx}{dt}\ne0

Dividimos las razones de cambio respecto a t para obtener la pendiente respecto a x.

Recta tangente

y-y(t_0)=\left.\frac{dy}{dx}\right|_{t=t_0}[x-x(t_0)]

Primero obtenemos el punto con t_0 y después evaluamos la pendiente.

Atención: si dx/dt=0 y dy/dt\ne0, la curva puede tener una tangente vertical.

Parte 2

Ejemplo guiado

Para x=t^2+1 y y=t^3-2t, encuentra la pendiente cuando t=1.

  1. Deriva cada coordenada respecto a t.
    \frac{dx}{dt}=2t,\qquad \frac{dy}{dt}=3t^2-2
  2. Forma el cociente.
    \frac{dy}{dx}=\frac{3t^2-2}{2t}
  3. Evalúa en t=1.
    \left.\frac{dy}{dx}\right|_{t=1}=\frac{3-2}{2}=\frac12
  4. El punto es (x(1),y(1))=(2,-1) y la pendiente tangente es 1/2.

Parte 3

Dos ejemplos resueltos

Derivadas directas.

Ejemplo 1
x=\cos t,\ y=\sin t\Longrightarrow \frac{dy}{dx}=\frac{\cos t}{-\sin t}=-\cot t
Ejemplo 2
x=t,\ y=t^2\Longrightarrow \frac{dy}{dx}=2t
