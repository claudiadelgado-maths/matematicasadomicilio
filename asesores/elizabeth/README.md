# Salón de Elizabeth

Perfil público de Elizabeth y entrada a los casilleros de Renata, Kevin, Gloria y Jimena. Los datos profesionales, comerciales y de disponibilidad se administran en maestro.json; las relaciones académicas se generan desde los metadatos de alumnos y sesiones.

La imagen pública está en /asesores/elizabeth/recursos/elizabeth.jpg. Cada casillero conserva la estructura que mejor corresponde a su contenido. Las sesiones ampliadas de Gloria, Jimena, Kevin y Renata presentan fórmulas revelables, explicaciones, ejemplos desarrollados y práctica con respuestas.

El contenido está orientado a universidad y utiliza KaTeX mediante matematicas.js. El comportamiento idéntico para revelar y ajustar fórmulas vive en recursos/js/sesiones-interactivas.js dentro del salón de Elizabeth; los estilos permanecen en el casillero correspondiente y no pasan a los recursos globales. Después de cualquier cambio, ejecuta npm run catalogo y npm run validar.
