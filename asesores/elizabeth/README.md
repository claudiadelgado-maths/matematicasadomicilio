# Salón de Elizabeth

Perfil público de Elizabeth y entrada a los casilleros de Renata, Kevin, Gloria y Jimena. Los datos profesionales, comerciales y de disponibilidad se administran en `maestro.json`; las relaciones académicas se generan desde los metadatos de alumnos y sesiones.

La imagen pública está en `/asesores/elizabeth/recursos/elizabeth.jpg`. Las sesiones comparten una estructura estable de tres partes:

1. teoría directa;
2. un ejemplo guiado paso a paso;
3. dos ejemplos resueltos sin desarrollo extenso.

El contenido está orientado a universidad y utiliza KaTeX mediante `matematicas.js`. Después de cualquier cambio, ejecuta `npm run catalogo` y `npm run validar`.
