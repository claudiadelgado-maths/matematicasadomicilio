# Casillero de Gloria

Casillero universitario con tres sesiones prácticas: reglas de derivación, reglas esenciales de integración y teorema fundamental del cálculo.

Las tres sesiones utilizan sesiones.css como recurso visual compartido únicamente dentro del casillero y el controlador común de sesiones interactivas ubicado en Elizabeth. El script permite revelar fórmulas mediante botones; no genera datos ni modifica los ejemplos con el tiempo. Cada tema conserva su propio HTML, su hoja estilos.css de entrada, ejemplos desarrollados y ejercicios con respuestas desplegables.

Cada sesión es un módulo atómico: puede relacionarse académicamente con otros temas, pero no presenta botones de continuación ni enlaces directos que impongan una secuencia entre sesiones. Su única salida contextual vuelve al casillero de Gloria.
