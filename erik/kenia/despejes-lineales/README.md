# Despejes lineales

Fecha editorial: `2026-08-19`.

Sesión publicada para Kenia sobre ecuaciones de la forma `Ax + B = C`. La idea compartida por los cuatro componentes es conservar la igualdad realizando la misma operación en ambos lados; no se presenta el procedimiento como «pasar» términos.

## Componentes

- `explicacion/`: recorrido progresivo desde `x + 3 = 7` hasta un ejemplo racional.
- `ejercicios/practica-de-despejes/`: banco de doce ecuaciones con enteros y distintas combinaciones de fracciones.
- `calculadoras/calculadora-de-despejes/`: resolución exacta y simplificada para valores enteros o racionales de A, B y C.
- `juegos/brigada-del-despeje/`: seis historias breves con personajes, números enteros y resultados sencillos.

`racionales.mjs` contiene la aritmética exacta compartida por ejercicios y calculadora. Si cambia su contrato, deben revisarse ambos componentes.
