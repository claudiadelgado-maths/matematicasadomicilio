# Brigada del despeje

Juego interactivo de la sesión **Despejes lineales** de Kenia.

- Presenta un banco de 20 misiones con personajes, escenas y contextos distintos.
- Cada ecuación se construyó desde una solución entera entre 2 y 9; no hay decimales ni fracciones.
- El alumno elige una de cuatro respuestas y nunca necesita escribir el resultado.
- Una respuesta incorrecta permite seguir intentando; una correcta muestra una explicación breve y suma una estrella.
- **Otra misión** avanza sin repetir personajes durante la ronda; al terminar las 20, comienza una nueva ronda mezclada.
- **Reiniciar brigada** borra las estrellas y empieza una ronda nueva.
- El personaje ocupa una escena independiente para no quedar oculto por la pregunta o las respuestas.

Condición de finalización: conseguir 20 estrellas, una por cada misión. El juego no depende del tiempo, del sonido ni únicamente del color, y funciona con teclado.

Ruta pública: `/erik/kenia/despejes-lineales/juegos/brigada-del-despeje/`.
