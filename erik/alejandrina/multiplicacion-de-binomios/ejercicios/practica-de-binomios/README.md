# Ejercicio

Práctica dinámica con coeficientes enteros dividida en tres fases independientes.

1. `Distribuir`: multiplica un monomio por un binomio y completa los coeficientes de `x²` y `x`.
2. `Organizar`: reescribe el producto de dos binomios como dos distribuciones sin resolverlas todavía.
3. `Simplificar`: completa los tres coeficientes del trinomio final.

Cada fase genera problemas nuevos, conserva su propio contador y utiliza desplegables para los signos. Las casillas numéricas reciben magnitudes enteras positivas; el signo se elige por separado. Una respuesta incorrecta ofrece una pista y permite reintentar sin revelar inmediatamente la solución.

`estilos.css` y `script.mjs` pertenecen únicamente a este ejercicio. La presentación de problemas y soluciones utiliza KaTeX.
