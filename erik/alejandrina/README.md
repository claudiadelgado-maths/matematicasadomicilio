# Espacio de Alejandrina

Índice de sesiones educativas personalizadas de Alejandrina.

Alejandrina pertenece al maestro `erik-estrella`. El índice carga automáticamente las sesiones publicadas desde `recursos/datos/academia.json`; no agregues tarjetas manuales.

## Contenido actual

- `sesiones/datos-no-agrupados/`: explicación, ejercicio, calculadora y juego de estadística descriptiva.
- `sesiones/diagramas-de-arboles/`: teoría, ejercicios, calculadora y juego publicados.
- `sesiones/medidas-de-posicion/`: teoría, ejercicios, conversor y juego publicados.

## Para una IA

No mezcles contenido con otros usuarios. Mantén el índice sincronizado con `usuario.json` y las carpetas reales. Evita datos personales innecesarios. Comprueba enlaces, móvil, escritorio y consola.
