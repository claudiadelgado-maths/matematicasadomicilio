# Calculadora didáctica de fracciones

Resuelve una operación elegida entre dos fracciones. Acepta signo externo y signos escritos en numerador o denominador.

## Salida

El procedimiento muestra entrada, normalización, fórmula general, método, sustitución, resultado directo, factorización, MCD, simplificación, resultado final y decimal exacto o periódico.

Valida denominadores cero, división entre una fracción cero y enteros fuera del rango didáctico. La aritmética exacta procede de `../../matematicas.mjs`.
