# ¿Cuánto pastel queda?

Genera un pastel SVG con entre 1 y 12 partes y una cantidad aleatoria de sectores azules. La persona escribe las partes que quedan sobre el total; cualquier fracción exactamente equivalente es válida.

Usa `../../pastel.mjs` para el SVG y `../../matematicas.mjs` para validar equivalencia y mostrar la forma simplificada.
