# Dame pastel

Genera una fracción propia o igual a uno con denominador entre 1 y 12. La persona selecciona sectores SVG hasta construirla.

Cada sector funciona con ratón, tacto, Enter y barra espaciadora, anuncia su estado con `aria-pressed` y conserva el foco después de cambiar. Usa `../../pastel.mjs` y `../../matematicas.mjs`.
