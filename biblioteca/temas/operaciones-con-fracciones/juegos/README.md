# Juegos de operaciones con fracciones

- `cuanto-pastel-queda/`: interpreta la parte coloreada y acepta cualquier fracción equivalente.
- `dame-pastel/`: construye una fracción propia o igual a uno seleccionando sectores SVG.

Ambos juegos usan `../pastel.mjs` para el dibujo y `../matematicas.mjs` para equivalencia y simplificación.
