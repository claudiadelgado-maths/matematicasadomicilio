# Ejercicios de operaciones con fracciones

Práctica dinámica de suma, resta, multiplicación y división.

## Niveles

1. Fracciones positivas y resultado directo exacto, sin simplificar.
2. Resultado irreducible, denominador positivo, enteros con denominador 1 y cero como `0/1`.
3. Signos en distintas posiciones; respuesta separada en signo, numerador absoluto y denominador.

Cada intento genera retroalimentación con operación original, regla, resultado directo, MCD y forma final. La lógica importa `../../matematicas.mjs`; no debe duplicarse aritmética racional en este módulo.
