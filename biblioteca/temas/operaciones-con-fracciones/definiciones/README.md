# Definiciones de fracciones

Consulta formal de los conceptos indispensables del tema `operaciones-con-fracciones`. Cada tarjeta contiene una definición matemática breve y una interpretación sencilla.

Este componente no sustituye la explicación didáctica y no contiene JavaScript local. La notación se renderiza con KaTeX 0.18.1 y conserva una representación textual si el recurso externo no está disponible.

Una IA debe leer `componente.json`, evitar incorporar conceptos generales ajenos a las fracciones, mantener la precisión formal y revisar acordeones, jerarquía, teclado, móvil y escritorio.
