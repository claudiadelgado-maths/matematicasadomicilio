# Teoría de operaciones con fracciones

Lectura progresiva desde la interpretación visual hasta operaciones con signos, simplificación y conversión decimal.

## Contenido real

- Fracción como parte, cociente y número racional.
- Equivalencia, comparación y normalización del signo.
- Suma y resta con denominadores iguales y distintos.
- Multiplicación y división, incluida la fracción compleja y el recíproco.
- Cuatro estrategias de simplificación.
- Operaciones con signos y dos procedimientos completos.
- Decimales exactos y periódicos.

La notación se renderiza con KaTeX 0.18.1 y conserva texto explicativo en español. La página no contiene lógica interactiva propia.
