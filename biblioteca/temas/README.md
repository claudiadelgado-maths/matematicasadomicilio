# Temas

Cada subcarpeta es una unidad educativa completa. Debe incluir `index.html`, `README.md` y `tema.json`. Solo contiene subcarpetas para explicaciones, ejercicios, juegos, demostraciones o calculadoras existentes.

Para añadir un tema consulta `/documentacion/creacion-de-temas.md`. El índice se genera desde los metadatos; no añadas tarjetas manuales.
