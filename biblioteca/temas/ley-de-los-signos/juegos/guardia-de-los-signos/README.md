# Juego: El guardia de los signos

Conserva la dinámica original: decidir `Pasa` o `No pasa` y terminar la partida con el primer error.

Cada ronda usa multiplicación o división entre los signos del visitante y la puerta. La retroalimentación muestra la igualdad, explica si los signos son iguales o diferentes y compara el resultado con el guardia. El foco se mueve a los controles relevantes para facilitar teclado.
