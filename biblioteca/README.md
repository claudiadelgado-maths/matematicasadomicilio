# Biblioteca

Catálogo público de recursos educativos. Sus tres colecciones visibles son Temas, Calculadoras y Exámenes.

## Límites

- Los índices enlazan módulos; no duplican su lógica.
- Un recurso específico se modifica en su propia carpeta.
- No se muestran categorías o componentes vacíos.
- `recursos/datos/catalogo.json` se genera desde metadatos con `npm run catalogo`.

## Para una IA

Conserva las rutas públicas y el sistema de tarjetas. Revisa los metadatos antes de cambiar un índice. No muevas un componente fuera de su tema salvo que cambie realmente su responsabilidad. Valida enlaces, móvil, escritorio y consola.
