# Exámenes

Cada examen tiene una carpeta propia con página, metadatos, contexto y recursos exclusivos. Un PDF debe permanecer dentro de `recursos/` del examen.

## Exámenes publicados

- `simulador-admision-universidad/`: simulador diagnóstico de admisión en formato PDF.
- `evaluacion-bachillerato/`: evaluación web estática de cinco problemas, con solución rápida y detallada desplegables y figuras SVG propias.

No anuncies un examen sin archivo o experiencia funcional. Revisa apertura en pestaña nueva, tamaño móvil, nombre accesible y rutas.
