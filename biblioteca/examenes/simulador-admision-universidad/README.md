# Simulador de admisión universitaria

Examen diagnóstico en PDF para practicar conocimientos matemáticos relacionados con admisión universitaria.

## Archivos propios

- `index.html`: presentación pública y acceso.
- `examen.json`: información del examen.
- `recursos/simulador.pdf`: documento que se abre en una pestaña nueva.

## Para una IA

No renombres el PDF ni cambies su ruta sin actualizar página y metadatos. Mantén visible que es un recurso de práctica, comprueba que abra en móvil y escritorio, y no agregues seguimiento ni recopilación de respuestas sin autorización.
