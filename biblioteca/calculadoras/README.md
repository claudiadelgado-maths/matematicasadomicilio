# Calculadoras

Índice global de herramientas publicadas. La implementación de cada calculadora permanece dentro de su tema; aquí solo se presentan enlaces.

No copies scripts ni estilos a esta carpeta ni añadas tarjetas manuales. Al añadir una calculadora, actualiza sus metadatos y ejecuta `npm run catalogo` y `npm run validar`; la tarjeta se genera automáticamente.
