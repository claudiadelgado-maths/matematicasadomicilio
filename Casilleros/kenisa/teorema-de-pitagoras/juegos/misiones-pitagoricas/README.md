# Misiones de Pitágoras

Tres versiones de cuatro situaciones reales; una versión aleatoria por partida.

Recursos compartidos exclusivamente dentro de esta sesión: recursos/app.mjs, modelo.mjs, figuras.mjs y sesion.css. Doce ilustraciones vectoriales con paletas y detalles por aventura: árboles, edificios con escaleras, jardines en vista superior, tienda, mástil y rampas. El triángulo, las medidas y la incógnita resaltada se conservan sobre el escenario; dibujos no a escala. Matemáticas con KaTeX. Navegación al menú y casillero; controles de teclado nativos. Probar corrección, reintentos, pantalla móvil y escritorio.
