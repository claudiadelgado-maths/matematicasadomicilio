01

MISMA ENTRADA, DOS RESULTADOS

Cuatro operaciones. Dos órdenes.

En suma, resta, multiplicación y división, ambas funciones reciben la misma entrada \(x\). Después operamos sus resultados. Conservaremos siempre \(f(x)=x+1\) y \(g(x)=2x\).

+

Suma

Sumamos las expresiones completas.

Orden \(f+g\)

\((f+g)(x)=(x+1)+2x=3x+1\)

En el otro orden

\((g+f)(x)=2x+(x+1)=3x+1\)
El orden no cambia la suma.
−

Resta

Los paréntesis ayudan a conservar los signos.

Orden \(f-g\)

\((f-g)(x)=(x+1)-2x=1-x\)

En el otro orden

\((g-f)(x)=2x-(x+1)=x-1\)
Aquí el orden sí cambia el resultado.
×

Multiplicación

Multiplicamos un resultado por el otro.

Orden \(f\cdot g\)

\((fg)(x)=(x+1)(2x)=2x(x+1)\)

En el otro orden

\((gf)(x)=(2x)(x+1)=2x(x+1)\)
El orden no cambia el producto.
÷

División

La función del denominador no puede valer cero.

Orden \(f/g\)

\(\left(\frac fg\right)(x)=\frac{x+1}{2x},\quad x\ne0\)

En el otro orden

\(\left(\frac gf\right)(x)=\frac{2x}{x+1},\quad x\ne-1\)
Cambian el cociente y su restricción.
Producto y composición usan ideas distintas. \((fg)(x)\) significa multiplicar \(f(x)\) por \(g(x)\). En cambio, \((f\circ g)(x)=f(g(x))\) significa meter una función dentro de la otra.

UN EJEMPLO CORTO

Simplificar es reunir lo que se puede reunir.

En la resta, quitamos los paréntesis y juntamos los términos con \(x\):

\((x+1)-2x=x+1-2x=1-x\)

Con este par de polinomios, suma, resta y producto están definidos para todo \(x\in\mathbb R\). Al dividir, conserva la restricción del denominador aunque más adelante simplifiques.

02

DE DENTRO HACIA FUERA

Una función entra en la otra.

En una composición, la salida de la función de dentro se convierte en la entrada de la función de fuera. Empieza por el paréntesis interior.

\(f(g(x))\)

Dentro: \(g(x)=2x\)Fuera: \(f\), que suma \(1\)
  1. Calcula primero \(g(x)=2x\).
  2. En \(f(x)=x+1\), cambia la entrada \(x\) por todo \(g(x)\).
\(f(g(x))=\underbrace{(2x)}_{\text{va dentro}}+1=2x+1\)

Multiplicar por dos → sumar uno.

\(g(f(x))\)

Dentro: \(f(x)=x+1\)Fuera: \(g\), que multiplica por \(2\)
  1. Calcula primero \(f(x)=x+1\).
  2. En \(g(x)=2x\), cambia la entrada \(x\) por todo \(f(x)\).
\(g(f(x))=2\underbrace{(x+1)}_{\text{va dentro}}=2x+2\)

Sumar uno → multiplicar por dos.

Con este par, \(f(g(x))\ne g(f(x))\). La composición, en general, depende del orden. Ambas están definidas para todos los reales porque estamos componiendo polinomios.

DEL CÁLCULO AL DOCUMENTO

Python que escribe tu LaTeX.

Copia el bloque completo en Python con SymPy instalado. La función of(f, g, operacion, evaluar=None) imprime texto plano con los delimitadores literales \[ y \], listo para pegar en tu documento. No tiene menú ni usa input().

sSuma: \(f+g\)
rResta: \(f-g\)
mProducto: \(f\cdot g\)
dCociente: \(f/g\)
fg\(f(g(x))\)
gf\(g(f(x))\)

Funciones: texto como "p + 1" o expresiones como p + sp.Rational(1, 2), definiendo antes p = sp.Symbol("p"). Escribe las potencias con ** y la multiplicación con *.

Variable: se detecta a partir de las funciones; admite \(p,v,u,t,x,y,z\), entre otras. Usa una única variable común. Si ambas son constantes o hay varias variables, el código pide corregir la entrada en lugar de adivinar.

Fracciones exactas: escribe "1/2" o sp.Rational(1, 2), también en evaluar. El valor 0 sí activa la evaluación. Para invertir suma, resta, producto o cociente, intercambia los dos primeros argumentos; los nombres locales \(f\) y \(g\) seguirán ese nuevo orden.

Original y simplificada: se guardan por separado. Solo aparece «Simplificando» si cambia la forma algebraica mostrada; sp.simplify puede conservar un producto factorizado. Una expresión de SymPy que ya llegó simplificada no permite reconstruir los pasos anteriores.

Ver el texto que imprimen las dos llamadas finales

Sin evaluar · primero \(f\), después \(g\)

Para las funciones
\[ f = p + 1 \]
\[ g = 2 p \]
La operación composición g después de f es
\[ g\left(f\left(p\right)\right) = 2 \left(p + 1\right) \]
Simplificando
\[ g\left(f\left(p\right)\right) = 2 p + 2 \]

Evaluando una fracción · primero \(g\)

Para la función
\[ f\left(g\left(p\right)\right) = 2 p + 1 \]
Al evaluar $p = \frac{1}{2}$ obtenemos
\[ f\left(g\left(\frac{1}{2}\right)\right) = 2 \]

El bloque utiliza las opciones de lectura sin evaluación automática y de impresión LaTeX de SymPy. La sesión muestra el código para ejecutarlo en Python.

import sympy as sp


def of(f, g, operacion, evaluar=None):
    """Imprime LaTeX literal. Usa expresiones propias de una misma variable."""
    nombres = {
        "s": "suma", "r": "resta", "m": "multiplicación",
        "d": "división", "fg": "composición f después de g",
        "gf": "composición g después de f",
    }
    if operacion not in nombres:
        raise ValueError("Usa s, r, m, d, fg o gf.")

    # Reutiliza los símbolos de las expresiones al leer entradas de texto.
    locales = {}
    for funcion in (f, g):
        if isinstance(funcion, sp.Expr):
            for simbolo in funcion.free_symbols:
                if simbolo.name in locales and locales[simbolo.name] != simbolo:
                    raise ValueError("Usa el mismo símbolo en ambas funciones.")
                locales[simbolo.name] = simbolo

    def leer(funcion):
        expresion = sp.sympify(
            funcion, locals=locales, rational=True, evaluate=False
        )
        if not isinstance(expresion, sp.Expr):
            raise ValueError("Cada función debe ser una expresión de SymPy.")
        return expresion

    f, g = leer(f), leer(g)
    variables = f.free_symbols | g.free_symbols
    if len(variables) != 1:
        raise ValueError("Debe haber una sola variable común; no se puede inferir entre varias o ninguna.")
    variable = next(iter(variables))

    def sustituir(expresion, valor):
        # .subs() puede operar antes de imprimir; esta copia conserva el árbol.
        if expresion == variable:
            return valor
        if not expresion.has(variable):
            return expresion
        argumentos = [sustituir(a, valor) for a in expresion.args]
        return expresion.func(*argumentos, evaluate=False)

    F, G = sp.latex(f), sp.latex(g)
    if operacion == "s":
        original = sp.Add(f, g, evaluate=False)
        original_tex = rf"\left({F}\right)+\left({G}\right)"
    elif operacion == "r":
        original = sp.Add(f, sp.Mul(-1, g, evaluate=False), evaluate=False)
        original_tex = rf"\left({F}\right)-\left({G}\right)"
    elif operacion == "m":
        original = sp.Mul(f, g, evaluate=False)
        original_tex = rf"\left({F}\right)\cdot\left({G}\right)"
    elif operacion == "d":
        if sp.simplify(g) == 0:
            raise ValueError("La función del denominador no puede ser cero.")
        original = sp.Mul(f, sp.Pow(g, -1, evaluate=False), evaluate=False)
        original_tex = rf"\frac{{{F}}}{{{G}}}"
    else:
        exterior, interior = (f, g) if operacion == "fg" else (g, f)
        original = sustituir(exterior, interior)
        # Los paréntesis muestran exactamente qué se coloca dentro.
        dentro = rf"\left({sp.latex(interior)}\right)"
        original_tex = sp.latex(exterior, symbol_names={variable: dentro})

    simplificada = sp.simplify(original)
    simple_tex = sp.latex(simplificada)
    cambia = sp.latex(original) != simple_tex

    def etiqueta(argumento):
        if operacion == "fg":
            return rf"f\left(g\left({argumento}\right)\right)"
        if operacion == "gf":
            return rf"g\left(f\left({argumento}\right)\right)"
        signo = {"s": "+", "r": "-", "m": r"\cdot", "d": "/"}[operacion]
        return rf"\left(f{signo}g\right)\left({argumento}\right)"

    def ecuacion(izquierda, derecha):
        print(r"\[ " + izquierda + " = " + derecha + r" \]")

    if evaluar is None:
        print("Para las funciones")
        ecuacion("f", F)
        ecuacion("g", G)
        print(f"La operación {nombres[operacion]} es")
        ecuacion(etiqueta(sp.latex(variable)), original_tex)
        if cambia:
            print("Simplificando")
            ecuacion(etiqueta(sp.latex(variable)), simple_tex)
    else:
        numero = sp.sympify(evaluar, rational=True)
        if not isinstance(numero, sp.Expr) or not numero.is_number or numero.is_finite is not True:
            raise ValueError("El valor de evaluación debe ser un número finito.")

        def comprobar(expresion, valor):
            calculo = sustituir(expresion, valor).doit()
            if calculo.has(sp.zoo, sp.nan, sp.oo, -sp.oo):
                raise ValueError("La operación original no está definida en ese valor.")
            return calculo

        # Comprueba las entradas originales antes de evaluar la simplificada.
        if operacion == "fg":
            comprobar(f, comprobar(g, numero))
        elif operacion == "gf":
            comprobar(g, comprobar(f, numero))
        else:
            comprobar(f, numero)
            valor_g = comprobar(g, numero)
            if operacion == "d" and sp.simplify(valor_g) == 0:
                raise ValueError("El denominador vale cero en ese número.")

        resultado = sp.simplify(simplificada.subs(variable, numero))
        print("Para la función")
        ecuacion(etiqueta(sp.latex(variable)), simple_tex)
        print(f"Al evaluar ${sp.latex(variable)} = {sp.latex(numero)}$ obtenemos")
        ecuacion(etiqueta(sp.latex(numero)), sp.latex(resultado))


if __name__ == "__main__":
    of("p + 1", "2*p", "gf")
    of("p + 1", "2*p", "fg", evaluar=sp.Rational(1, 2))
