# Trivia de multiplicaciones

Juego de `tablas-de-multiplicar-elyan`, usuario `elyan-claudia`, fecha 2026-10-15. Ruta pública `/Casilleros/elyan/tablas-de-multiplicar/juegos/trivia/index.html`.

Diez preguntas ordenadas para una tabla o veinte mezcladas, dos distintas por cada tabla. Cuatro respuestas. Una elección puntuable, respuesta correcta visible, Siguiente, resumen y repetición. Cambiar modo o tabla reinicia; sin persistencia de respuestas.

Sin teoría ni límite de tiempo. Acceso desde el menú; enlaces para volver o cambiar al otro juego. `index.html`, `estilos.css`, `script.mjs` y `juego.json` describen esta actividad. El CSS importa `../../recursos/sesion.css`; la lógica usa `../../recursos/modelo.mjs`. Los SVG son propios de la sesión. Base, navegación y marca globales sin cambios.

Contrato de persistencia, accesibilidad, cancelación de animaciones y pruebas en `../../README.md`. Ejecutar el test del modelo desde la raíz, catálogo y validador.
