# Explicación: datos no agrupados

Explicación progresiva de datos no agrupados dentro de la sesión de Alejandrina. Define el vocabulario, desarrolla una tabla de seis columnas, interpreta frecuencias y porcentajes acumulados, compara gráficas y explica media, mediana y moda con situaciones reales.

## Archivos y dependencias locales

- `index.html`: teoría, fórmulas, tablas, ejemplos y navegación interna.
- `script.mjs`: genera las dos gráficas del ejemplo de libros con la lógica compartida.
- `estilos.css`: incorpora `../estadistica.css`, exclusivo de esta sesión.
- `componente.json`: metadatos del recurso.

La notación usa la integración de KaTeX adoptada por el proyecto. `script.mjs` importa `../estadistica.mjs`; no copies esa lógica dentro del componente.

## Comprobaciones

- La tabla de libros debe sumar \(n=10\), frecuencia relativa \(1\) y porcentaje \(100\%\).
- La frecuencia acumulada debe terminar en \(10\) y el porcentaje acumulado en \(100\%\).
- Las gráficas deben coincidir con la tabla, conservar una altura controlada y permitir desplazamiento horizontal.
- Revisa KaTeX, jerarquía, enlaces, teclado, 360–1440 px y consola.

No conviertas esta explicación en un tema público sin decisión expresa.
