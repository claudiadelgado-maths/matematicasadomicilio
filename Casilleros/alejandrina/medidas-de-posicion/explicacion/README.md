# Explicación: Medidas de posición

Teoría visual y estática de la sesión de Alejandrina.

## Objetivo

Comprender cuartiles, deciles, percentiles y mediana como nombres para posiciones dentro de un recorrido del 0% al 100%.

## Contenido

- idea de posición sin trabajar con conjuntos de datos;
- división del recorrido en 4, 10 y 100 partes;
- reglas `Q1 = 25%`, `Dn = n × 10%` y `Pn = n%`;
- equivalencia central `Q2 = D5 = P50 = Mediana = 50%`;
- comparación de equivalencias exactas;
- ejemplo físico con un hilo;
- ejemplo de relación similar al examen;
- resumen de consulta rápida.

## Límites

No incluye interpolación, fórmulas de posición, listas de datos, tablas de frecuencia, datos agrupados ni cálculo del valor que ocupa una posición.
