# Explicación · Fórmulas de sucesiones aritméticas

Recorrido conceptual de la segunda sesión de sucesiones de Alejandrina.

Parte de `aₙ = a₁ + (n − 1)d`, presenta los despejes para `a₁`, `d` y `n`, explica las condiciones de cada división y termina con un ejemplo que reconstruye una sucesión a partir de dos términos no consecutivos.

La explicación distingue entre identificar `a₁` al leer una lista y calcularlo cuando solo se conoce otro término. También interpreta el signo de `d` como creciente, decreciente o constante.
