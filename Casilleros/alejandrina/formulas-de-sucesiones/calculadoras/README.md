# Calculadora · Fórmulas de sucesiones aritméticas

Herramienta educativa con tres calculadoras relacionadas:

1. encuentra `d` a partir de dos términos y sus posiciones;
2. encuentra la posición `n` a partir de `aₙ`, `a₁` y `d`;
3. encuentra `aₙ` a partir de `a₁`, `d` y `n`.

Todas validan campos vacíos, posiciones no enteras, divisiones entre cero y resultados que no representan una posición entera positiva. La primera presenta fracciones simplificadas cuando la diferencia no es entera. La tercera actualiza una vista previa en LaTeX al escribir cada dato, incluso antes de calcular.
