# Explicación de sucesiones aritméticas

Recorrido conceptual de la primera sesión del bloque.

## Recorrido

1. Un patrón cotidiano que cambia siempre en la misma cantidad.
2. Distinción entre posición `n` y valor `aₙ`.
3. Diferencia común positiva y negativa.
4. Construcción de la fórmula mediante `n − 1` saltos desde el primer término.
5. Anatomía interactiva de `aₙ = a₁ + (n − 1)d`.
6. Ejemplos guiados para construir una fórmula, encontrar un término y comprobar el resultado.
7. Errores conceptuales frecuentes.
8. Resumen visual de comprensión.

`script.mjs` controla únicamente el selector accesible de elementos de la fórmula. Las expresiones estáticas se renderizan con KaTeX, usan delimitadores explícitos y los bloques matemáticos largos conservan desplazamiento horizontal interno. La presentación evita fondos oscuros y cajas matemáticas decorativas.
