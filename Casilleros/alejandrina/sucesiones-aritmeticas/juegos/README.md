# Ruta de las sucesiones

Juego de tres niveles con cinco preguntas por nivel. Todas las respuestas se eligen mediante botones: no hay que escribir números ni completar campos.

## Niveles

1. **Completa el patrón:** encuentra un término faltante en una sucesión creciente.
2. **Identifica los elementos:** alterna preguntas sobre a₁, d, a₃, a₄ y a₅; aparecen también diferencias negativas.
3. **Trabaja con la fórmula:** elige la fórmula correcta o selecciona el valor de a₁₀ y a₁₅.

Cada pregunta genera una nueva sucesión desde el recurso compartido sucesiones.mjs. Las opciones incorrectas representan errores frecuentes: usar n en vez de n − 1, cambiar el signo de d, intercambiar a₁ y d o confundir una posición con su valor.

Cada reto presenta cuatro botones de respuesta. La partida registra puntuación, aciertos, errores y porcentaje. Al terminar identifica el concepto con más errores para sugerir un repaso. Reiniciar genera una partida completamente nueva y no guarda información en el navegador.
