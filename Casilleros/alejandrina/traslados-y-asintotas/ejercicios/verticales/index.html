03 / Asíntotas verticales

Resuelve. Simplifica.
Encuentra las barreras.

El denominador siempre será cuadrático. Aprende a distinguir dos raíces, una raíz doble, ninguna raíz real y los huecos.

EntenderExplorarPracticar

El denominador da candidatos, no la respuesta final

Un cero abajo
necesita una segunda mirada.

Hay una asíntota vertical x = a cuando la función crece o decrece sin límite al acercarse a a por al menos un lado. Para estas funciones racionales, revisa las raíces que quedan en el denominador tras simplificar.

01 · Resuelve

Denominador = 0

Para ax² + bx + c, usa factorización o la fórmula general: x = (−b ± √(b² − 4ac)) / (2a). El discriminante Δ = b² − 4ac indica: Δ > 0, dos raíces reales; Δ = 0, una raíz doble; Δ < 0, ninguna raíz real.

02 · Simplifica factores

Cancelar no es borrar términos.

Solo puedes cancelar factores comunes del numerador y denominador. Si desaparece todo el factor que causa ese cero, hay un hueco, no una vertical.

03 · Comprueba

¿Sigue quedando ese factor abajo?

Entonces sí hay vertical. Por ejemplo, cancelar un (x − 2) de (x − 2)² todavía deja x − 2 en el denominador.

El dominio siempre conserva las exclusiones del denominador original, aunque simplifiques. Dos raíces no garantizan dos asíntotas; una raíz doble cuenta como un solo valor de x.
