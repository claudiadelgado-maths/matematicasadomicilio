Tres casos para saber a qué altura se acerca una función racional cuando x se aleja mucho.

Compara el grado más alto

Tres casos.
Una regla para cada uno.

Una asíntota horizontal y = L indica que f(x) se acerca a L cuando x → +∞ o x → −∞. En estas racionales, ambos extremos tienen la misma horizontal cuando existe.

Grado de arriba < grado de abajo

y = 0

El denominador crece más rápido. Ejemplo: un numerador lineal sobre uno cuadrático.

Grado de arriba = grado de abajo

Divide los coeficientes principales.

Si arriba comienza con 3x² y abajo con 2x², la horizontal es y = 3/2. Conserva los signos.

Grado de arriba > grado de abajo

No hay horizontal.

En un cúbico sobre un cuadrático puede aparecer una asíntota oblicua. No confundas «sin horizontal» con «sin asíntotas».

Una horizontal sí puede cruzarse. Describe lo que ocurre lejos, no una pared que la curva jamás pueda tocar. El grado es el exponente mayor con coeficiente distinto de cero.
