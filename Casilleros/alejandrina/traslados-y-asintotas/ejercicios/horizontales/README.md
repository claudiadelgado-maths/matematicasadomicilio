# 02 · Asíntotas horizontales

Módulo de `traslados-y-asintotas-alejandrina`, publicado y registrado en `ejercicio.json`. URL: `/Casilleros/alejandrina/traslados-y-asintotas/ejercicios/horizontales/index.html`.

Tres casos de comparación de grados: menor → y = 0; iguales → cociente de coeficientes principales; mayor → ninguna horizontal. Todos los denominadores originales son cuadráticos. La explicación diferencia una recta horizontal de una vertical y aclara que la gráfica puede cruzar una horizontal. El laboratorio permite cambiar entre los tres casos, ampliar el intervalo de x y consultar f(x) para valores lejanos.

Banco de 52 funciones. Rondas de ocho con entrada del valor de y o selección explícita de ausencia, pistas, reintentos, procedimiento, gráfica y revisión final. Acepta fracciones exactas y punto/coma. Sin almacenamiento. Usa recursos compartidos de la sesión; detalles de validación, archivos y comprobaciones en `../../README.md`.
