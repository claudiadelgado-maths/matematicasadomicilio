# 04 · Encuentra ambas asíntotas

Módulo de `traslados-y-asintotas-alejandrina`, publicado y registrado en `ejercicio.json`. URL: `/Casilleros/alejandrina/traslados-y-asintotas/ejercicios/ambas/index.html`.

Combina horizontal y verticales. Denominador original siempre cuadrático y numerador lineal, cuadrático o cúbico. Laboratorio con un caso de cada grado y un cúbico con cancelación; se puede revelar/ocultar el análisis y las marcas de asíntotas/hueco. Refuerza que una horizontal se escribe y = b, una vertical x = a y un hueco es un punto ausente.

Banco de 58 funciones, incluidas raíces dobles, fraccionarias, cancelaciones y ausencia de verticales. Rondas de ocho con horizontal (o ausencia) y todas las verticales en el mismo formulario. Una respuesta es correcta únicamente si ambas partes coinciden. Pistas, reintentos, procedimiento completo, gráfica y revisión final. Sin almacenamiento. Usa recursos compartidos de la sesión; detalles de validación, archivos y comprobaciones en `../../README.md`.
