04 / Asíntotas horizontales y verticales

Dos preguntas.
Una misma función.

Combina las dos estrategias con numeradores lineales, cuadráticos o cúbicos y denominadores cuadráticos.

EntenderExplorarPracticar

Dos estrategias que se complementan

Lejos: grados.
Cerca: factores.

Horizontal · y = …

Compara grados.

Con denominador cuadrático: numerador lineal → y = 0; cuadrático → cociente de coeficientes principales; cúbico → ninguna horizontal.

Vertical · x = …

Resuelve y revisa cancelaciones.

Encuentra las raíces del denominador cuadrático. Solo las que siguen anulando el denominador después de simplificar son verticales.

Control final

Escribe rectas, no puntos.

Una vertical se escribe x = a; una horizontal, y = b. Un hueco sí es un punto excluido de la gráfica. No lo cuentes como asíntota.

Puedes tener ambas clases, solo una o ninguna. Las cancelaciones no recuperan puntos del dominio original y no convierten una asíntota vertical en horizontal.
