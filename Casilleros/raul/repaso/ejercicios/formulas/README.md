# Sustitución en fórmulas

Apartado de Sustitución y evaluación de expresiones, dentro de Repaso de Raúl (Erik).

Laboratorio de fórmulas. Explicación breve, ejemplo resuelto y generación dinámica. Navegación secuencial; regreso al alumno.

Recursos comunes en `../../recursos/sustitucion/`: `motor.mjs` (árbol de expresiones y aritmética racional), `actividad.mjs` (interacciones accesibles), `sustitucion.css` (estilo propio). Importa el motor racional de Repaso sin modificarlo. KaTeX con representación vertical alternativa si no carga. Sin almacenamiento ni llamadas a servicios para evaluar respuestas.

Permite ratón, táctil y teclado. En colocación de valores se puede arrastrar o seleccionar tarjeta y destino. Botón Nuevo ejercicio limpia el estado. Verificar entradas vacías, signos, errores, reinicios, móvil, consola y enlaces; ejecutar catálogo y validación.
