# Sesiones de Andrés

Cada subcarpeta representa una sesión independiente y debe incluir index.html, README.md, sesion.json y únicamente los componentes disponibles.

## Sesiones actuales

- crecimiento-y-decrecimiento-exponencial/ (2026-11-15): continuación de interés compuesto; aumentos y disminuciones repetidos, factor, gráfica, tabla, cambio acumulado, recuperación del inicio y diez retos guiados.
- interes-simple-y-compuesto/ (2026-10-13): explicación, simulador, gráfica, tabla dinámica y retos sobre montos finales con tasa fija.
- teorema-de-tales/ (2026-09-22): proporcionalidad con paralelas, laboratorio, ejemplo guiado y juego.
- porcentajes/ (2026-08-10): porcentajes, datos, descuentos, aumentos e IVA, con teoría, ejercicios, calculadoras y juego final.

La secuencia porcentajes → interés compuesto → cambio exponencial conecta las tres sesiones de ese bloque. Tales pertenece al bloque geométrico.

El índice de Andrés se genera automáticamente desde los metadatos; no se agregan tarjetas manualmente. Al cambiar contenido, sincroniza README, metadatos y este inventario. Ejecuta npm run catalogo y npm run validar.
