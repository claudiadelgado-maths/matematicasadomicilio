# Interior, clausura y frontera

Segunda sesión del recorrido de Sofía. Estudia interior, clausura, exterior y frontera mediante criterios de vecindades, propiedades, un ejemplo guiado en la recta real, un ejemplo en un espacio finito, casos contrastados, errores frecuentes y seis ejercicios resueltos.

Las demostraciones y soluciones utilizan desplegables nativos accesibles. La sesión conserva un enlace a «Espacios topológicos» para repasar la estructura de abiertos cuando sea necesario.
