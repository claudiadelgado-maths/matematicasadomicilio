# Espacio de Sofía

Casillero universitario de Sofía en la colección de casilleros. Su recorrido introduce la estructura de espacio topológico y después estudia interior, clausura y frontera.

Ambas sesiones desarrollan la teoría paso a paso e incluyen ejemplos guiados, comparaciones, demostraciones, errores frecuentes y ejercicios con soluciones desplegables.

Las sesiones publicadas se obtienen de `recursos/datos/academia.json`; no se mantienen tarjetas manuales.
